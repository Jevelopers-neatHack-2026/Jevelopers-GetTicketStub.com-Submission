# Logo usage

All files are in `logo/`, generated by `tools/build_logos.py` from Fraunces outlines. Re-run the script rather than editing the SVGs by hand.

## Which file

| Situation | File |
|---|---|
| Light background, full colour | `ts-stamp.svg`, `lockup-horizontal.svg`, `lockup-stacked.svg` |
| Dark background | `ts-stamp.svg` (foil reads on ink), or `ts-stamp-mono-cream.svg` |
| One-colour print, foil or emboss | `ts-stamp-mono-ink.svg`, or `ts-stamp-currentcolor.svg` in code |
| Busy photo or art behind | Mono stamp on a cream or ink plate. Never the bare stamp. |
| Browser tab, 16–32 px | `favicon.svg` |
| App stores, home screen | `app-icon.svg` (export 1024 px PNG; let the OS apply the corner mask) |
| Wordmark under 120 px wide | `wordmark-compact.svg` |

## Clear space and minimum size

- **Clear space:** keep at least the width of one perforation tooth (stamp width ÷ 7) clear on every side of the stamp. For lockups, keep the height of the "s" clear.
- **Minimum sizes:**
  - Stamp: 24 px tall on screen, 8 mm in print. Below that, use `favicon.svg`.
  - Perforated wordmark: 120 px wide. Below that, use the compact wordmark.

## Colour

- **Gradient:** the stamp is either foil (copper → orange → cyan, 135°) or one solid brand colour (orange, ink or cream). There are no other gradients, tints or outlines.
- **Letters:** on the foil stamp the letters are Night Ink. On mono stamps they are knocked out, so the background shows through.

## Misuse

- Rotating, skewing or adding a drop shadow. A physical stamp on a mockup may sit at an angle; the logo file itself never does.
- Re-typesetting "Ts" in another font.
- Changing the number of perforations. The 7 × 9 grid is part of the mark.
- Placing it on a mid-tone where neither ink nor cream reaches 3:1.
