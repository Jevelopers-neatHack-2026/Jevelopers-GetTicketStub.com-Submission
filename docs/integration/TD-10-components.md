# TD-10 shared component slice

This private package contains local reusable presentation components and a built-package consumer example. It does not complete issue #15, a financial view, TD-11, or the actual-host release gate. Financial producers and authenticated host integration remain unavailable. Samples are **synthetic UI display samples, not producer-approved finance fixtures**. No canonical finance schema, arithmetic, ledger, permission decision, budget mutation, report generation or download is implemented here.

## Inventory and presentation contract

Import components and types from `@jevelopers/team-dashboard` and CSS from `@jevelopers/team-dashboard/style.css`. Render them inside `Dashboard`, or a host-owned `.team-dashboard` wrapper. Styles and pinned variables are isolated under this class; container-width queries let the navigation collapse inside narrow or enlarged host mounts; no document/root reset, font request, global token assignment, service or production server is added. Existing base-path and mount contracts remain in [mount-contract.md](mount-contract.md).

| Component | Supplied inputs and behavior |
| --- | --- |
| AmountText | Discriminated available/unknown/restricted/unavailable display; exact supplied text and currency. No parsing, rounding, conversion, summation or inference of zero. |
| MetricCard / StateBadge | Labelled metric region; independent textual valuation, reconciliation, evidence, stale/partial/access indicators. Restricted amount suppresses optional description and badges. |
| ScopeContext | Approved display labels for project, period and currency; restricted/unavailable suppress other fields. No identity or authorization derivation. |
| FilterSelect | Native labelled, controlled select with optional description and disabled choices. Emits an allowed choice; host owns filtering and scope policy. |
| Pagination | Controlled page description and supplied previous/next availability. Disabled controls are native. No guessed record count or page total. |
| DataTable | Native caption, column and row headers; supplied projected cells only. Practical minimum column widths and unbroken amount/currency text are preserved inside a scoped horizontal scroller. Native Scroll left/right buttons work with Enter/Space and ArrowLeft/ArrowRight/Home/End, including read-only tables without evidence links. Controls remain focusable with aria-disabled at boundaries so Home/End can reverse direction; unavailable click actions are ignored. An inner content track keeps viewport-width scroll controls visible at left/middle/right positions, including enlargement. Measurements run only after browser mount, update state only when geometry changes, and clean up observers/listeners/timers. No page overflow or hidden/truncated essential fields. Controlled sort emits intent and exposes aria-sort, without sorting or calculating data itself. |
| BreakdownChart / Tooltip | Supplied normalized plot coordinates in [-1,1] scale only geometry. Invalid/nonfinite coordinates do not draw. Every item has an always-visible equivalent table with unchanged supplied amount/currency/access. Text labels and left/right legend convey meaning independently of color. Tooltips support focus, hover, persistence over their text, blur and Escape even when another control has focus. |
| EvidenceLink / ReturnToResults | Approved presentation URL or fixed restricted/unavailable fallback. Host navigation callback handles ordinary internal activation; modified clicks preserve native behavior. External links are annotated and use noopener/noreferrer. |

These are UI projection types, not shared-contracts replacements. The authenticated host must minimize/redact producer data before passing it, approve visible labels and IDs, supply permission decisions, reconcile state axes and produce exact amount strings. Do not pass raw producer records, secrets, customer metadata, raw storage URLs or unauthorized labels. A restricted cell does not authorize visibility of its row identifier: host approval of every projected field is required. React keys are not an authorization boundary. No logging or fetching is performed by these patterns.

`EvidencePolicy` is a host-owned allowlist of exact origins, path-prefix boundaries and optional query keys. Protocol-relative URLs, credentials, fragments, nonapproved origins/paths/query keys, unsafe schemes, controls, malformed escapes, dot segments before URL normalization, encoded/nested slash ambiguity and reserved credential query keys (even if allowlisted) are rejected. Credential names are case/separator normalized; token, secret, password, signature, credential, authorization, API/access key and bearer names, plus auth/key/sig/code/JWT/session names, are reserved. HTTP is accepted only for the same supplied origin (local harness); production hosts should supply HTTPS origins. Allowlisted query *values* and permitted labels must already be safe, minimal host projections; this policy does not establish server authorization or inspect the target document. Rejection emits neither the raw URL nor the sensitive supplied label/title. `onNavigate` receives only the accepted normalized href. Changing the policy cannot grant backend access.

## Navigation and sample identity

The fixture is a real npm-pack archive consumer, prepared by `scripts/prepare-fixture.mjs`; it imports the extracted distribution, not source component implementations. Its synthetic sample source `tests/fixtures/td10-display.ts` defines exact zero `0.000000000 USD`, negative `-12345678901234567890.000000137 USD`, sub-cent `0.000000137 EUR`, unknown and restricted examples, a long noncustomer identifier and independent estimated/reconciled/evidence labels. Expected text is asserted verbatim. These examples are neither producer fixtures nor a financial correctness oracle.

Open `/admin/finance?examples=components` in the local fixture. Navigation uses the declared route hierarchy: Overview -> Transactions -> synthetic record -> Return to results, and Reports preview. Project/period/currency context, controlled sample/page query parameters and sort intent persist across those transitions. Headings receive focus on route changes; return restores focus to the exact initiating example record (negative or sub-cent). A direct/reloaded detail, removed result or missing origin falls back to the Transactions heading, never a different record. Only explicit known transaction sample IDs display amounts; unknown transaction/event IDs show unavailable content and safe return navigation. Current page labels and route navigation remain owned by the foundation. Other declared routes can render the same examples; their financial implementations are still pending. Reports are display-only and produce no file.

## Validation and rollback

Run clean `npm ci`, `npm run lint`, `npm run typecheck`, `npm test -- --run`, `npm run build`, `npm pack --dry-run`, `npm run check:contrast`, `npm run test:e2e`, `npm run test:integration`, and focused `npm run test:e2e -- --grep TD-10`. Use separate loopback `TD_TEST_PORT` values for concurrent worktrees. `TD_ARTIFACT_DIR` controls sanitized screenshots, full axe JSON and Playwright results; keep these outside tracked product files. `npm run test:host` intentionally exits nonzero until genuine host revisions/mount/auth/producer evidence exist; passing fixture checks do not bypass it.

Contrast uses WCAG sRGB luminance with unrounded threshold comparisons. Ink/cream is ~15.645:1; 66% ink muted text/cream is ~5.532:1 (not the rounded 5.6 claim in upstream prose). Orange, copper and cyan on cream fail normal-text contrast in explicit negative controls, so they are not body-text colors. Screenshots and browser console/network checks supplement axe. The suite fails page errors, console errors or nonloopback requests. Independent review findings TD10-R1 (narrow table readability), R2 (wrong originating focus) and R3 (unknown detail fallback to a known amount) were corrected with geometry/keyboard scrolling, both-record/reload/missing-result focus and unknown-ID regressions. Original independent artifacts and early test failures and their dispositions are retained in the run artifacts rather than erased from the report.

Rollback is a repository revert of this isolated component commit; the private archive is never published. No data migration, server state, deployment or provider credential is involved. Hosts may continue using the previous foundation distribution until actual consumer review is complete.

Primary validation guidance: [Playwright accessibility testing](https://playwright.dev/docs/accessibility-testing), [WAI native sortable table example](https://www.w3.org/WAI/ARIA/apg/patterns/table/examples/sortable-table/), [WCAG text contrast](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html), [non-text contrast](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html).
