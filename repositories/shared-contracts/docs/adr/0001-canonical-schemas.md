# ADR 0001: JSON Schema wire definitions and offline ESM bindings

Status: implemented foundation candidate; producer/consumer acceptance pending.

Use JSON Schema 2020-12 in schemas as the sole wire source. Schema IDs are `https://schemas.jevelopers.org/<Contract>/<exact-semver>` identifiers, resolved only from local files; generation never downloads schemas. Ajv 8.17.1 compiles all supported versions together. esbuild 0.25.12 bundles the generated validators and their helper into standalone ESM; installed runtime has no npm dependencies. json-schema-to-typescript 15.0.4 generates declarations, with a TypeScript 5.9.3 AST pass adding readonly fields/arrays. Branded primitive annotations are in canonical schemas, not competing hand-written wire definitions. Runtime API declarations are generated by the toolchain, separate from schema-derived payload types.

The required npm/Node ESM commands and canonical JSON Schema override general skill preferences for Bun, pnpm or Zod. No Zod, OpenAPI copy or consumer-local parallel definition becomes canonical. Lock tool versions with package-lock.json; Node 22.23.3 meets the harness >=22.23.3 <23 baseline. Package and schema versions are independent; generated/schema-manifest.json records each schema's exact-byte digest and build tools. Source revision remains null until an actual reviewed release mapping exists.

Validators never coerce, add defaults, remove fields, mutate input or fetch. Public helpers return discriminated Results with typed code, JSON-pointer path and optional keyword; no input value or arbitrary diagnostic message is copied. Unsupported exact versions, including unsupported majors, fail at /schema_version. Object keys and enum values are closed; optional is absent unless null is explicitly specified. The version policy preserves current and previous accepted majors during coordinated migrations, with 90 days' notice and all consumer acknowledgements/fixtures before removal. No historical accepted major exists yet, so none is invented.

`private: true` prevents accidental registry publication. npm pack is a local review archive only; no license, tag, package publication, provider call or infrastructure creation is implied. Approval, ledger, budget, output rendering and authenticated adapters remain downstream.
