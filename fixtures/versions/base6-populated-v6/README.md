# Populated V6 version-store migration fixture

This fixture is an actual V6 SQLite database produced by opening the checked-in populated V4 fixture with the qualified V6 store implementation from commit `5ab7f0ede215e62f6ddb5ef3472a2dc8e55cbc74`. The migration runs offline and keeps the completed generation, edit, inspection, immutable versions, usage evidence, selection, and content-addressed artwork. Its [manifest](manifest.json) pins the source database, resulting database, requests and artifact bytes.

The current [API integration test](../../../tests/versions/api-integration.test.mjs) opens this populated V6 database, migrates it additively through storage schema 13, reopens it and replays the historical operations without dispatch. The inspection-session/stage tables are created without synthesizing sessions for historical jobs. The [composition authority tests](../../../tests/versions/composition-authority.test.mjs) also verify that a final-v13 migration failure rolls populated V4/V6 state back. These are local fixture checks, not production-host migration acceptance.
