The exporter retains provider-reported cost only when supplied as a finite value; otherwise it remains absent/unknown. No production per-span provider-cost or billing receipt is retained. The owner's no-further-AI-spend report is based on no LLM span/zero reported provider attempts, not independently verified accounting.
