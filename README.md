> **For people who want to keep the night, TicketStub is the keepsake studio that turns any ticket into a stub worth framing. No forms: drop your ticket and it's done.**

Paper by day, foil by night. The everyday studio is cream stock and ink; the moments that sell the stub move to a dark stage, because foil only glows against dark. Open **[`index.html`](index.html)** for the visual brand board, or read **[`SPEC.md`](SPEC.md)** for the compact text spec.

## Status

The core identity lives here, and getticketstub.com already ships byte-identical copies of all 14 logo SVGs. It has not been ratified, versioned or packaged.

- **In the repository:** 14 outlined logo SVGs generated by [`tools/build_logos.py`](tools/build_logos.py), DTCG tokens with CSS and Tailwind outputs, both font families with their licences, the brand board and the guidance docs listed below.
- **Pending:** ratifying the identity ([BK-02 #9](https://github.com/Jevelopers-neatHack-2026/brand-kit/issues/9)), versioned distribution and an approved export subset ([BK-03B #14](https://github.com/Jevelopers-neatHack-2026/brand-kit/issues/14)), asset provenance ([BK-06 #7](https://github.com/Jevelopers-neatHack-2026/brand-kit/issues/7)) and the v1 gate ([BK-10 #5](https://github.com/Jevelopers-neatHack-2026/brand-kit/issues/5)), all under [BK-EPIC #4](https://github.com/Jevelopers-neatHack-2026/brand-kit/issues/4). Relevant acceptance criteria stay planned in the [acceptance view](docs/architecture/ACCEPTANCE.md).
- **Open, not merged:** [PR #3](https://github.com/Jevelopers-neatHack-2026/brand-kit/pull/3) repoints the edition and foil links to `getticketstub.com/docs/studio/` and proposes moving the app to "always on paper". Until it merges, `main` keeps "paper by day, foil by night".
- The stub-edition reference in [SPEC.md](SPEC.md#two-tiers) still points at `ticket-studio`, which does not exist in the organization ([ownership notes](docs/architecture/OWNERSHIP.md#existing-compatible-decisions)).
- The [architecture views](docs/architecture/OWNERSHIP.md) describe intended boundaries; they do not establish completed product functionality, passing implementation tests, connected sponsor tools or live financial activity.

## Use the tokens

```css
@import "brand-kit/tokens/tokens.css";
.button { background: var(--ts-cta-bg); color: var(--ts-cta-label); border-radius: var(--ts-radius-control); }
```
```html
<section class="ts-night">…</section>  <!-- switches this subtree to the night stage -->
```

The Tailwind preset reads the same CSS variables. There is no published package yet; copy or vendor a pinned revision until [BK-03B](https://github.com/Jevelopers-neatHack-2026/brand-kit/issues/14) defines distribution.

## Rebuild the logos

The SVGs in `logo/` are generated. Re-run the script instead of editing them by hand ([logo usage](docs/logo.md)).

```sh
python -m pip install fonttools uharfbuzz
python tools/build_logos.py
git status --short logo/   # no output means the outputs are unchanged
```

The script takes no arguments. It shapes `fonts/Fraunces[SOFT,WONK,opsz,wght].ttf` with HarfBuzz, so the SVGs need no installed font, and overwrites the 14 files in `logo/`. Dependencies are not pinned. On 2026-10-11 it reproduced every tracked SVG byte for byte with Python 3.14.4, fonttools 4.66.1 and uharfbuzz 0.56.3.

## Related repositories
