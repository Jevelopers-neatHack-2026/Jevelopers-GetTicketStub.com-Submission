> **For people who want to keep the night, TicketStub is the keepsake studio that turns any ticket into a stub worth framing. No forms: drop your ticket and it's done.**

Paper by day, foil by night. The everyday studio is cream stock and ink; the moments that sell the stub move to a dark stage, because foil only glows against dark. Open **[`index.html`](index.html)** for the visual brand board, or read **[`SPEC.md`](SPEC.md)** for the compact text spec.

## Quickstart

The offline source checks use Git, Make and Python 3. There is no root npm package or product server. From a clone:

```sh
git clone https://github.com/Jevelopers-neatHack-2026/brand-kit.git
cd brand-kit
make check
```

Open [index.html](index.html) in a browser to review the brand board. It requests Google Fonts; network access and font delivery are separate from the offline checks. The [standing brand constraints](docs/brand-governance.md#standing-constraints) prohibit self-hosting brand fonts in product integrations. Bundled TTFs and their OFL notices remain source/provenance material; their presence is not a deployment instruction.

Logo rebuilding additionally needs `fonttools` and `uharfbuzz` in an isolated Python environment. The optional Tailwind integration check needs Node 18 or newer and npm, as declared by [the development fixture](tools/tokens-dev/package.json). See the validation table below for commands that download dependencies.

## Use the tokens

```css
@import "brand-kit/tokens/tokens.css";
.button { background: var(--ts-cta-bg); color: var(--ts-cta-label); border-radius: var(--ts-radius-control); }
```
```html
<section class="ts-night">…</section>  <!-- switches this subtree to the night stage -->
```

The examples assume a locally available `brand-kit/` path resolved by your project; it is not a published npm package. The Tailwind preset (Tailwind 3.4.x) reads the same CSS variables. `tokens.css` no longer loads web fonts; opt in with `@import "brand-kit/tokens/external-fonts-google.css";` (it contacts Google, see the [token profile](docs/token-profile.md#external-fonts)). Regenerate with `make build-tokens`; never hand-edit the generated files. Pin any local review copy to an exact revision and retain its notices. Product distribution remains subject to [BK-03B](https://github.com/Jevelopers-neatHack-2026/brand-kit/issues/14), provenance and export approval.

## Rebuild the logos

The SVGs in `logo/` are generated. Re-run the script instead of editing them by hand ([logo usage](docs/logo.md)).

```sh
python -m pip install fonttools uharfbuzz
python tools/build_logos.py
git status --short logo/   # no output means the outputs are unchanged
```

The script takes no arguments. It shapes `fonts/Fraunces[SOFT,WONK,opsz,wght].ttf` with HarfBuzz, so the SVGs need no installed font, and overwrites the 14 files in `logo/`. Dependencies are not pinned. On 2026-10-11 it reproduced every tracked SVG byte for byte with Python 3.14.4, fonttools 4.66.1 and uharfbuzz 0.56.3.

## Testing and validation

| Command | Checks | Dependencies and limits |
|---|---|---|
| `make check` | Inventory, local links, governance document shape, provenance-register structure, token determinism and unit tests | Offline Python checks; passing does not approve an asset or release |
| `make check-inventory` / `make check-links` | Tracked-file coverage and supported local Markdown/HTML links | External URLs are reported as unchecked |
| `make check-governance` | Required governance-document structure | Does not verify reviewer identity or approval |
| `make check-provenance-register` | Provenance shape, coverage and recorded hashes | Explicit unknown rights may pass this structural check |
| `make check-tokens` | Token rules, deterministic regeneration, output drift and token tests | No npm required; does not certify accessibility or consumer adoption |
| `make test` | Python unit tests for the source validators | Includes intentional failing fixtures; use the final test result |
| `make check-tokens-tailwind` | Actual Tailwind build against the locked development fixture | Runs `npm ci`; requires network for missing dependencies and Node/npm |
| `make check-links-external` | External URL probes | Network-dependent; response availability is not approval or provenance |
| `make check-provenance` | Production export eligibility | Separate from `make check`; currently fails closed on missing rights/approvals and the unapproved export subset |

There are no product-service environment variables. The optional Google font stylesheet changes network behavior when a consumer explicitly imports it. See [inventory checks](docs/inventory-checks.md), [token profile](docs/token-profile.md) and [provenance](docs/provenance.md) for the detailed boundaries.
