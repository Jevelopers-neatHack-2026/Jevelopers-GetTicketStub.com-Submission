# print-production

Print composition and production manifests.

## Implementation status

PP-01A implements a strict Node 24 / TypeScript ESM runtime foundation: offline
Chromium SVG-to-PNG/PDF calibration, exact environment/font/browser pins, typed
verification failures and a fail-closed suite dispatcher. Production behavior
and canonical consumer contracts remain planned. No provider connection or
supplier/approval/purchase/ledger authority is implemented.

[Runtime setup, commands, evidence and limitations](docs/runtime/README.md)
describe the implemented local surface and pending Linux CI validation.
