# marketing-material

Collateral inventory, draft claims and provenance policy, conceptual visuals, and future launch material.

## Implementation status

The repository contains maintained policy/navigation documents and a draft synthetic collateral bundle. The diagram, fictional ticket mockup, HTML support page, generated 150-second silent synthetic rehearsal, transcript/captions, X key visual and scoped render/redaction evidence are not product screens or approved publication assets. The rehearsal is distinct from the required final product demo, which remains absent at `demo/exports/v1-demo.mp4`. No application workflow, provider connection, product result, or license is implied.

Architecture integration documents the intended boundaries. It does not establish completed product functionality, passing implementation tests, connected sponsor tools, or live financial activity.

The inventory records the preserved documentation baseline, all tracked files, current draft visual families, planned collateral, and evidence/approval dependencies. Exact copy rows map every handoff phrase, HTML fragment, and accessible alternative to a claim or CTA and pinned provenance/checksum. Scoped author pixel, metadata, contrast, browser, accessibility, and synthetic redaction evidence is recorded; independent review, source-owner rights, and destination approval remain pending. A draft is not a released asset; repository visibility does not grant permission to publish individual material.
